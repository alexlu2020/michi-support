隱私權政策

適用於 Michi 日常旅算 App 及本支援網站。

生效日期 2026 年 11 月 13 日

裝置上的資料

Michi 無需註冊或登入。App 在裝置上保存計算紀錄、標記、偏好設定、旅遊設定與最後成功取得的參考匯率，用於下次開啟時恢復使用。計算金額、紀錄和旅遊設定不會傳送給匯率服務。Michi 不提供雲端同步，也未整合廣告或追蹤 SDK。

匯率連線與服務供應商

App 透過 Cloudflare Workers 請求公開參考匯率。Worker 另行向 Frankfurter 取得公開匯率。App 只請求匯率資料，請求不包含你的計算內容或目的地。Cloudflare 在提供連線、維護安全與排查問題時，可能處理 IP 位址、請求時間、狀態碼等連線資訊。Cloudflare Workers Logs 依服務方案保留 3 或 7 天。詳見 Workers Logs 說明與 Cloudflare 隱私權政策。

保留、刪除與選擇

自動紀錄保留最新 100 筆。你可以在「標記」頁刪除個別標記或清除全部標記。刪除 App 可移除裝置上由 App 保存的資料。系統備份由你的裝置設定管理。關閉 App 的網路連線可停止新的匯率請求，仍可使用一般計算及先前保存的匯率。

網站與支援回報

本網站由 GitHub Pages 託管。網站本身未加入追蹤程式、廣告或表單。GitHub 可能為網站服務與安全處理連線資訊。若你透過 GitHub Issues 送出回報，你的帳號名稱及發文內容會公開，並由開發者用來處理你提出的問題。回報會留在 GitHub，直到內容遭移除。GitHub 的資料處理方式與保留規則請參考 GitHub 隱私權聲明。

聯絡及資料權利

Michi 由 GitHub 帳號 alexlu2020 的開發者營運。如有隱私疑問、想撤回先前提供的資訊，或希望移除你提交的支援資料，請透過支援頁聯絡。請先簡述需求，避免在公開留言附上個人資料。政策有更新時，會在此頁公布並標示生效日期。
